# 👑 LBank Buyer — ربات تلگرام مدیریت درخواست‌ها

ربات حرفه‌ای تلگرام با **Python 3.11+ ، Aiogram 3 ، SQLAlchemy 2 (async) ، PostgreSQL** برای ثبت و بررسی درخواست خرید اکانت، گیفت، تیکت و پشتیبانی — با پنل مدیریت کامل **داخل تلگرام**.

## ✨ امکانات
- عضویت اجباری در کانال‌ها (قابل مدیریت از پنل) + مسدودسازی ادامه کار تا زمان عضویت
- منوی اصلی: خرید اکانت، گیفت، ثبت تیکت، پشتیبانی، قوانین، حساب کاربری
- ثبت درخواست ۵ مرحله‌ای (مبلغ ← سال ← مدارک غیرحساس ← خلاصه ← ثبت) با جلوگیری از درخواست تکراری
- پنل مدیریت: آمار، کاربران، درخواست‌ها، گیفت، تیکت، پیام همگانی، ویرایش متن‌ها، ظاهر، کانال‌ها، ادمین‌ها، تنظیمات
- ۵ سطح دسترسی: مدیر کل، مدیر درخواست‌ها، مدیر پشتیبانی، مدیر محتوا، مدیر کاربران
- **تمام متن‌ها و دکمه‌ها از پنل قابل ویرایش‌اند** (بدون تغییر کد)، با متغیرهای پویا:
  `{first_name} {username} {user_id} {amount} {year} {request_id}` و چند متغیر کمکی دیگر (هر متن راهنمای متغیرهای خودش را نشان می‌دهد)
- پشتیبانی از ایموجی پرمیوم (Custom Emoji) با جایگزینی خودکار با ایموجی معمولی
- گیفت داخلی و Telegram Gift واقعی به‌صورت دو قابلیت جدا
- ضداسپم، ثبت لاگ فعالیت ادمین‌ها، پشتیبان‌گیری JSON (دستی و خودکار برای مدیران کل)

## 📁 ساختار پروژه
```
LBank-Buyer/
├── main.py                 # نقطه شروع
├── bot/
│   ├── handlers/           # بخش کاربر (start, buy, gifts, tickets, misc, fallback)
│   ├── keyboards/
│   ├── middlewares/        # session دیتابیس، دسترسی/ضداسپم/عضویت اجباری
│   ├── services/           # متن‌ها، تنظیمات، ارسال، اعلان، پشتیبان، همگانی
│   └── states/

├── database/               # مدل‌ها، session، seed
├── config/
├── utils/                  # متن‌های پیش‌فرض، رندر Entity، ابزار بازیابی پشتیبان

```

## 🚀 راه‌اندازی محلی
1. ربات را در [@BotFather](https://t.me/BotFather) بسازید و توکن بگیرید.
2. آیدی عددی خودتان را از ربات‌هایی مثل @userinfobot بگیرید.
3. ```bash
   python -m venv venv && source venv/bin/activate      # ویندوز: venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env      # BOT_TOKEN و ADMIN_IDS را پر کنید
   python main.py
   ```
   اگر `DATABASE_URL` را تنظیم نکنید، برای تست محلی از SQLite استفاده می‌شود؛ برای تولید حتماً PostgreSQL بگذارید.
4. در تلگرام `/start` و برای پنل `/admin` را بزنید.

## 🚂 استقرار روی Railway
1. پروژه را در GitHub بارگذاری کنید (یا از Railway CLI استفاده کنید).
2. در Railway: **New Project → Deploy from GitHub repo**.
3. **+ New → Database → Add PostgreSQL** بزنید.
4. در سرویس ربات، بخش **Variables**:
   - `BOT_TOKEN` = توکن ربات
   - `ADMIN_IDS` = آیدی عددی مدیران کل (با کاما)
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (Reference به سرویس Postgres)
5. Railway فایل `Procfile` را می‌خواند و پردازش `worker: python main.py` اجرا می‌شود. (در صورت نیاز در Settings → Start Command را `python main.py` بگذارید.)
6. جداول در اولین اجرا خودکار ساخته می‌شوند و داده‌ها بعد از ری‌استارت/دیپلوی حفظ می‌مانند (دیتابیس PostgreSQL پایدار است).

> ⚠️ مهم: حالت مراحل گفتگو (FSM) در حافظه است؛ اگر ربات وسط ثبت درخواست ری‌استارت شود، کاربر باید همان مرحله را از منو دوباره شروع کند. تمام داده‌های ثبت‌شده در دیتابیس امن هستند.

## 🛠 کار با پنل مدیریت
| بخش | کاربرد |
|---|---|
| 📝 ویرایش متن‌ها | دسته را انتخاب کنید → متن → «ویرایش» → متن جدید (همراه فرمت/ایموجی پرمیوم) را بفرستید. «پیش‌نمایش» و «بازنشانی» هم دارد. |
| 🔘 دکمه‌ها | در همین بخش، دسته «دکمه‌ها». (برچسب دکمه‌ها متن ساده است.) |
| 🎨 ظاهر | جداکننده `{sep}`، روشن/خاموش‌کردن ایموجی پرمیوم، کتابخانه ایموجی |
| 📣 کانال‌ها | یوزرنیم/لینک/آیدی کانال را بفرستید. **ربات باید ادمین کانال باشد.** |
| 👮 ادمین‌ها | فقط مدیر کل؛ مدیران تعریف‌شده در `ADMIN_IDS` قابل حذف نیستند. |
| ⚙ تنظیمات | یوزرنیم پشتیبان، اجباری‌بودن مدرک، سقف درخواست باز، حداقل/حداکثر مبلغ، ضداسپم، پشتیبان‌گیری |

### ✨ ایموجی پرمیوم
1. پنل ← مدیریت ظاهر ← کتابخانه ایموجی ← افزودن: یک پیام با ایموجی پرمیوم بفرستید تا Custom Emoji ID ذخیره شود و یک نام لاتین بدهید (مثلاً `gold`).
2. در هر متن بنویسید `{e:gold}`؛ یا مستقیم در ویرایش متن، ایموجی پرمیوم را بفرستید.
3. اگر تلگرام نمایش را برای ربات مجاز نکند، ایموجی معمولی نشان داده می‌شود (خطا ایجاد نمی‌شود).

**محدودیت تلگرام:** نمایش Custom Emoji در پیام‌های ربات معمولاً نیازمند شرایطی مثل داشتن یوزرنیم‌های خریداری‌شده از Fragment است؛ در غیر این صورت ایموجی عادی (fallback) دیده می‌شود. همچنین Bot API امکان ایموجی پرمیوم روی خود *دکمه‌های اینلاین* را به‌صورت عمومی ندارد، پس برچسب دکمه‌ها ایموجی معمولی‌اند.

### 🌟 Telegram Gift واقعی
پنل ← مدیریت گیفت ← «ارسال Telegram Gift واقعی». هزینه از **موجودی Stars خود ربات** کسر می‌شود؛ اگر موجودی کافی نباشد، پیام خطا دریافت می‌کنید. این قابلیت جدا از گیفت داخلی (دارای موجودی/محدودیت) است.

## 💾 پشتیبان‌گیری و بازیابی
- دستی: پنل ← تنظیمات ← پشتیبان‌گیری دیتابیس (فایل JSON برای شما ارسال می‌شود).
- خودکار: هر N ساعت (پیش‌فرض ۲۴) برای مدیران کل ارسال می‌شود (قابل تنظیم/خاموش‌کردن). مدیران کل باید یک‌بار ربات را استارت کرده باشند.
- بازیابی روی دیتابیس **خالی**: `python -m utils.restore فایل.json`
- برای امنیت بیشتر، پشتیبان‌گیری خود PostgreSQL در Railway را هم فعال کنید.

## 🔐 نکات امنیتی
- ورودی‌ها اعتبارسنجی می‌شوند؛ در مرحله مدارک فقط تصویر/فایل پذیرفته می‌شود و **هیچ متن آزادی (رمز، کد ورود و...) ذخیره نمی‌شود**.
- ضداسپم بر پایه تعداد پیام در بازه زمانی، قابل تنظیم از پنل.
- هر بخش پنل با سطح دسترسی ادمین کنترل می‌شود و عملیات مهم در `admin_logs` ثبت می‌شود.
- فایل `.env` را هرگز منتشر نکنید.
